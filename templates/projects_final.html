AI-Powered Job Application Intelligence System

A decision engine that turns job applications into a trackable funnel with deterministic fit scoring — not a portfolio, a measurement system.

Problem

Job applications disappear into a black box. With a 24% recruiter view rate but only 4% call conversion, visibility was not the bottleneck — conversion was. There was no signal for which applications deserved follow-up and which were genuine mismatches.

Solution

Built a two-LLM fit assessment pipeline: a JD parser extracts must-have, important, and nice-to-have skills; a matcher compares them against the resume using a controlled vocabulary with three-layer fuzzy normalisation. A deterministic scoring layer (weights: 3/2/1) produces reproducible confidence scores independent of model variance. Every assessment attempt is auditable with a six-code failure taxonomy separating precondition from execution failures.

Impact

Identified 4–5 high-intent recruiters through repeat visit tracking and GA4 behavioural events joined to application records via ref code. Diagnosed AI insight inaccuracies in v1.1 as a data quality gap — redesigned the schema before touching the model. Signal conflict diagnostics now surface where LLM qualitative scores diverge from deterministic confidence labels.

My Role

End-to-end owner across three shipped versions: product framing, schema design, FastAPI backend, two-LLM prompt architecture, vocabulary normalisation, deterministic scoring logic, four-state assessment lifecycle, GA4 behavioural event layer, and private analytics dashboard with priority and disagreement signals derived at read time.

Marketing Campaign Performance & Budget Optimization Dashboard

Built a decision-focused dashboard to diagnose funnel inefficiencies and optimize budget allocation across multi-language ad campaigns.

Problem

Marketing campaigns across regions were generating inconsistent results, with varying costs per subscription (CPS). There was no clear visibility into where users dropped off in the funnel or which campaigns deserved more budget.

Solution

Built an interactive Power BI dashboard analyzing the full funnel (Impressions → Clicks → Installs → Activations → Subscriptions). Identified bottlenecks using conversion rates and conditional formatting, and connected CPS/CTR with spend analysis to guide budget allocation decisions.

Impact

Enabled clear identification of scalable vs inefficient campaigns, surfaced actionable fixes (CTR issues in Marathi, post-click conversion gaps in Malayalam), and supported budget allocation simulations to target a blended CPS of ~₹280.

My Role

Designed the analytical framework, built the full Power BI dashboard (data modeling, DAX measures, and visuals), and translated insights into practical growth actions focused on real decision-making.
