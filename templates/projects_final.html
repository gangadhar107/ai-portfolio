A self-measuring portfolio that turns job applications into a trackable funnel.

Marketing Campaign Performance & Budget Optimization Dashboard

Built a decision-focused dashboard to diagnose funnel inefficiencies and optimize budget allocation across multi-language ad campaigns.

Problem

Marketing campaigns across regions were generating inconsistent results, with varying costs per subscription (CPS). There was no clear visibility into where users dropped off in the funnel or which campaigns deserved more budget.

Solution

Built an interactive Power BI dashboard analyzing the full funnel (Impressions → Clicks → Installs → Activations → Subscriptions). Identified bottlenecks using conversion rates and conditional formatting, and connected CPS/CTR with spend analysis to guide budget allocation decisions.

My Role

Designed the analytical framework, built the full Power BI dashboard (data modeling, DAX measures, and visuals), and translated insights into practical growth actions focused on real decision-making.

Facial Emotion Recognition System

Real-time emotion detection from live webcam feed using MobileNetV2 transfer learning on the FER2013 dataset.

Problem

Human emotion is a critical signal in applications like mental health monitoring, customer experience analysis, and human-computer interaction. Manual observation is not scalable and existing lightweight models trained on the FER2013 dataset struggle with its inherent label noise, class imbalance, and low image resolution, making reliable real-time emotion classification genuinely difficult.

Solution

Upgraded a previous CNN-based system to a MobileNetV2 transfer learning architecture trained on FER2013 (36K images, 7 emotion classes). Implemented two-phase fine-tuning, first training only the classification head with the base frozen, then unfreezing the top 30 layers for fine-tuning. Deployed the model for real-time inference using OpenCV with Haar cascade face detection and per-class confidence visualisation on live webcam feed.

Impact

Achieved 49% test accuracy on FER2013, a dataset with a documented human-level ceiling of approximately 65% due to crowd-sourced label noise and severe class imbalance (disgust class is 16x underrepresented relative to happiness). Model runs in real-time on CPU with confidence thresholding and uncertainty flagging, making it practically deployable without GPU hardware.

My Role

Owned the full pipeline independently including data preprocessing, augmentation strategy, two-phase training with callbacks, evaluation via confusion matrix and classification report, and real-time inference deployment. Diagnosed the Disgust and Fear class failures as dataset-level problems rather than model failures, and identified concrete next steps including class weighting and label smoothing.
